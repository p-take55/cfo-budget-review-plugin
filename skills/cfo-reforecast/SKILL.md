# 見通し・予算の更新

当初予算、前回予測、実績、今回の変更理由と本人の判断を読む。実績期間を固定し、残り期間の数量・単価・費用・時期等を更新する。
実績の増減をそのまま将来へ延長せず、継続要因、一時要因、未確認要因を分ける。未採用案の効果は別シナリオにする。
当初予算との差と前回予測との差を別々に示す。採算と資金予測へ同じ前提を渡し、更新先と計算時点を残す。

成果は更新予測、変更前後の前提、理由・証拠、資金への影響、次の確認日。予測更新と承認済み予算の改定を区別する。
予算の改定が必要なら本人へ判断を返し、採用後も旧版を保存する。未確定事項を履歴から消して確定した事実のように見せない。
