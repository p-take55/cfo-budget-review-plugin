# 予算と実績の差異分析

比較対象の承認済み予算の版、実績の締め状況、期間、通貨、分類を揃える。未締めの暫定実績を確定月次と混ぜない。
実績－予算を基本の符号として、売上増と費用増で意味が異なることを明示する。予算ゼロの増減率を無限大や通常の比率にせず金額で示す。
単価、数量、構成、単位費用、固定費、計上時期、一時要因へ分解し、差額合計を照合する。費用の未計上や支払遅れを節約成果としない。

不足データと説明できない残差を残す。採算変化の分析が利用できる場合は同じ定義を再利用する。
成果は重要な差、根拠、繰り返す可能性、対応候補。原因が不明なら確認することを示し、実績に合わせて当初予算を変更して差を消さない。
