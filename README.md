# 予算・月次経営管理

予算づくり、予算と実績の差の分解、月次のまとめ、見通しの更新の 4 つの Skill。

[CFO](https://github.com/p-take55/aachat-cfo) の Skill のうち、予算・月次経営管理にあたるものを Plugin にまとめたものです。単独で入れても使えます。

## 同梱の Skill

| Skill | すること |
|---|---|
| `cfo-budget-plan` | 目標から予算と事業計画を作る |
| `cfo-budget-variance` | 予算と実績の差を理由ごとに分ける |
| `cfo-monthly-review` | 今月の結果と来月の重点をまとめる |
| `cfo-reforecast` | 最新の実績で、残りの期間の見通しを直す |

## 使うときに

数字の元になる資料、扱う事業・期間・通貨、守りたい残高や使える予算を、要る範囲で渡してください。手元の資料からでも、使える接続からでも始められます。

- 実績・予定・仮定、利益と入出金、本人の工数を分けて扱い、分からない金額をゼロで埋めません。
- 外部サービスとつなぐ設定（MCP・認証）、定期実行、通知は同梱していません。
- 送金・注文・支払・借入・投資の取引・税の申告・契約の変更・外への送信はしません。この Plugin を入れたことを、それらの許可とは受け取りません。
